Nature Image Portfolio
A visually appealing and responsive image portfolio website built using HTML and CSS Grid.
This project showcases beautiful nature scenes including sunsets, waterfalls, mountains, trees, sea, clouds, and flowers in a modern grid layout.

🚀 Features

✅ Responsive Grid Layout
✅ Clean and Modern UI Design
✅ Image Hover Effects
✅ Proper Image Alignment using CSS Grid
✅ Fully Responsive Design

🛠️ Technologies Used

HTML5
CSS3
CSS Grid
Flexbox
